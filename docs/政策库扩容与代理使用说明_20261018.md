## 一、代理怎么接进来（已自动生效）

代理配置只有一处，写在 `collector/config.yaml:17-19`：

```yaml
settings:
  proxy: "http://127.0.0.1:7897"   # Clash Verge 默认端口；换客户端只改这一行
```

写在这里之后：

| 源的类型 | 实际行为 | 代码位置 |
|---|---|---|
| `needs_proxy: true` 的源 | **走代理**；若 proxy 为空又没设 `HTTPS_PROXY`，直接报错，不会偷偷直连 | `collector/fetcher.py:get_session(force_proxy=True)` |
| 其余所有源（gov.cn、工信部、统计局、Federal Register、六大博客里的 OpenAI/DeepMind/NVIDIA/Anthropic） | **强制直连**，连系统环境变量里的代理都不认 | `collector/fetcher.py:51-53`（`session.trust_env = False`） |

这就是你要的"只在采那两个站时开代理"：**代理开着也只会被 needs_proxy 的源使用**，国内源永远走直连，不会被带出去。

### 只跑需代理的源（不用整轮重跑）

```bash
python -m collector update --proxy-only      # 只采 needs_proxy 的 RSS 源
python -m collector backfill oecd            # 只算 OECD
python -m collector backfill govuk           # 只算英国 gov.uk
```

### 常见错误

- 报 `该源标记 needs_proxy，但 settings.proxy 未配置且无 HTTPS_PROXY 环境变量`
  → 代理没开或端口不对。先用浏览器确认 Clash 的混合端口（Verge 默认 7897）。
- 代理开了但全失败
  → 代理客户端可能只代理浏览器（PAC/规则模式）。把端口确认后，`curl -x http://127.0.0.1:7897 https://api.oecd.ai/policy-initiatives/public?page=1` 能返回 JSON 才算通。
