### 4. 代理机制已落地（这是你最关心的"只在这两个站开代理"）

- 配置唯一入口：`collector/config.yaml:17-19` 的 `settings.proxy: "http://127.0.0.1:7897"`。
- `needs_proxy: true` 的源走代理；**其余源强制直连**（`session.trust_env = False`，连系统代理都不认）→ 国内源不可能被带出去。
- 只跑需代理的源：`update --proxy-only` / `backfill oecd` / `backfill govuk`。
- 详细说明见 `docs/政策库扩容与代理使用说明_20261018.md`。
