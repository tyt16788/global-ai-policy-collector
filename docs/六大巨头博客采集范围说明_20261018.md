## 四、全文是硬性入库标准

按你的要求，**博客数据必须抓全文，不接受只存 RSS 摘要**。具体口径与政策层完全一致：

| 项 | 口径 |
|---|---|
| 入库条件 | `full_text` 非空且正文 ≥ 200 字 |
| 只拿到摘要的记录 | `fulltext_status = failed:仅摘要`，**不计入"全文已抓"** |
| 单条截断 | 5 万字（与政策层一致，控制表体积） |
| 失败重试 | 每轮 `fulltext` 自动重试，连续 3 轮失败 → 标记 `failed:放弃`，不再空转 |
| 溯源 | `url` 列永远保留原文入口，可人工复核 |

**现有政策层全文现状（基准线）**：3,070 / 3,438 = **89.3%**，平均 13,241 字/条。
失败 368 条 = 国家统计局 343（文章页 JS 渲染，静态抓不到）+ 工信部/cac 反爬 25（HTTPError，重试不会自愈）。

**博客层的全文路径**：

| 公司 | 全文怎么拿 | 难度 |
|---|---|---|
| OpenAI | RSS 给摘要 → 抓 `/news/xxx` 正文页，取 `article` 容器 | 中（页面有 JS，需解析） |
| DeepMind | 同上，`/blog/xxx` 正文 | 中 |
| NVIDIA | 同上，`blogs.nvidia.com/xxx`（WordPress，正文好取） | 低 |
| Anthropic | 无 RSS，先解析列表页拿链接，再抓 `/news/xxx` 正文 | 高（两跳 + 无 feed） |
| Meta / Microsoft | 已用替代源补齐（见第三节） | 中 |

> 注意：博客全文的"反爬"比政府站更严（Cloudflare、JS 渲染、字体混淆）。NVIDIA/OpenAI 实测可直连取页面，但正文抽取的稳定性需要跑一轮后抽检 30 条校准选择器。

### 2. 32 条失败的真实原因（不是选择器问题）

OpenAI 在连续抓取约 1,000 篇后开始返回 **Cloudflare 挑战页**（HTTP 403，页面正文只有 "Enable JavaScript and cookies to continue"），属于 **IP 级限流冷却**，不是正文容器选错。已做两件事：

- `config.yaml` 给 OpenAI 加 `rate_limit: 2.5`（每 2.5 秒一条，原来全站统一 1.0 秒）；
- 记录保留 `failed:` 状态，下轮自动重试；**隔几小时或换网络再跑一轮大概率能补齐**。

另有 1 条 DeepMind 是 404（文章已下线），无法补。

### 3. 本轮为质量做的四处额外改造

| 改造 | 原因 | 位置 |
|---|---|---|
| `clean_article_text()` 离线清洗 | 初版正文把"推荐阅读"区块、按钮词、"C h a t G P T"这种散开标题一起抓了进来 | `collector/sources/company_blog.py` |

| 标题去掉栏目前缀 | Anthropic 卡片把 "Announcements/Policy" 拼进标题 | 同上，`strip_title_prefix()` |
| 补齐人类可读日期格式 | `Oct 14, 2026` 这类格式解析失败，导致 Anthropic 11 条发布日期为空 | `collector/normalize.py` 的 `_DATE_FORMATS`（+12 个格式） |

## 八、复现方法

```bash
# 元数据（RSS 发现文章 + 摘要）
python -m collector blog

# 元数据 + 全文（推荐；--limit 控制本轮补多少条）
python -m collector blog --fulltext --limit 300

# 只补失败的全文（下轮自动重试，无需额外命令）
python -m collector fulltext

# 规则/清洗调整后，离线回溯修正历史记录（不联网）
python -m collector blog --clean

# 导出信号库视图
python -m collector export --xlsx --signals
```

配置全部在 `collector/config.yaml` 的 `company_blogs:` 段：`mode`(rss/html)、`feed_url`/`list_url`、`article_selector`、`rate_limit`、`ai_filter`、`needs_proxy`、`enabled`。

> 复现时间 2026-10-18。feed 条数会随时间变化（尤其 NVIDIA 18 条属滚动窗口），写论文时以实际抓取结果为准。
