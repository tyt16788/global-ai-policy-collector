# 全球 AI 政策数据收集工作报告

**日期**：2026-10-16 ｜ **系统**：global-ai-policy-collector v5（CSV 存储版）
**用途**：毕业研究"多源新兴技术主题识别与潜力评估" Stage E —— 政策佐证数据层

---

## 一、本次做了什么

1. **架构重构**：放弃原 1–4.py 的单脚本 + SQLite 方案，重构为 `collector/` Python 包，
   存储层改为**单一 CSV 主表**（`data/policy_master.csv`，含全文列），guid 去重追加，无 SQL。
2. **三路采集**：
   - **中国回填**：gov.cn 国务院政策文件库官方检索 API（国务院文件 + 部委文件，
     "人工智能 / 生成式人工智能 / 大模型 / 智能体"四组关键词 × 标题/全文双检索）
   - **美国回填**：Federal Register 官方 API（"artificial intelligence" + "AI" 全文检索）
   - **RSS 增量**：工信部、gov-rss 聚合（8 部委）、国家统计局、NIST、EU AI Act Tracker 等直连源
3. **全文抓取**：为每条政策抓取原文写入主表 `full_text` 列——
   美国走 Federal Register 官方纯文本接口（`raw_text_url`，免爬虫）；
   中国 gov.cn 解析 `#UCAP-CONTENT` 正文容器；其余爬链接页启发式抽取。
4. **工程配套**：源健康检查、运行日志、疑似重复报告、原子落盘（防文件占用），
   GitHub Actions 每日北京时间 09:00 自动增量采集并提交到仓库 `data` 分支。

## 三、数据质量说明

- **去重**：URL 归一化（去跟踪参数、统一 https、排序查询参数）哈希为 guid；
  同"国家+标题+日期"不同网址仅 7 组疑似重复（美国多机构联合发文所致），已在报告列出待人工裁决。
- **AI 标注**：`ai_tags` 列用中英文关键词打标（只标注、不过滤），供后续佐证匹配时自行筛选口径。
- **政策类型**：gov.cn 统一为"政策文件"（文号/分类在 `extra_json`）；美国分
  最终法规 / 法规草案 / 通知公告 / 总统文件；欧盟为法规动态。

## 四、已知限制

1. **368 条全文失败（10.7%）**，全部来自 RSS 源：
   国家统计局 343（其文章页为 JS 渲染，静态抓取拿不到正文）、工信部 17、gov-rss 8。
   这些记录保留标题、摘要、网址，`fulltext_status` 列标记失败原因；RSS 源本身只占库内 17%，
   且统计局数据发布对"政策佐证"价值有限，影响可控。
2. **OECD.AI（全球 70+ 国家）未入库**：本地直连被墙。代码已就绪，
   GitHub Actions 云端（墙外）每日运行时会自动回填，届时日/韩/英/德/法等国数据会自动补齐。
3. **英国 DSIT、欧盟数字战略两个 RSS 源**本地同样需代理，云端可正常抓取。
4. 单条全文截断为 5 万字（覆盖 90% 以上文件；p99 曾触及 10 万字上限，为控制主表体积而设），
   完整原文永远可通过 `url` 列溯源。
